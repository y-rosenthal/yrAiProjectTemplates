# What's in this repo?

This repo contains templates for structuring projects that are 
intended to be developed with the aid of an LLM or similar AI. 

Each subfolder contains a template that is intended for a specific
type of project. As of right now, there is only one "genericTemplate" template
which is intended to be used for all types of projects (e.g. websites, other
software development, writing books, etc.)

Within each subfolder are folders for differen versions of that template
e.g. genericTemplate/v0.0.1.
This facilitates each perusal of different versions of the templates
without needing to rely on git commands.

## README.md

The file you are currently reading describes this repository of templates.
However, each template contains its own README.md that is intended
to describe the contents of the project that uses that template.
When instantiating one of these templates for use in a particular project, 
the developers of the project should put their own info in the template's
README.md to describe their project.
